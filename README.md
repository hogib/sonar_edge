# sonar-edge

Marine-debris detection on forward-looking sonar frames, trained in Python and
deployed as a dependency-free C11 runtime on a Raspberry Pi. See `docs/PLAN.md`.

## Shipped model

`runtime/weights.h` is `small` at 360x240 (78 M MACs; `runs/small_360_cv_f0`): pooled 5-fold mAP
52.6 +- 1.9 over three seeds, 63.8 mAP on the development test fold in C (bit-exact with the
Python int8 model), 20 ms per frame on one laptop core. Regenerate with
`uv run python -m sonar_edge.export_c runs/<run> && make -C runtime clean all test`.

## Segmentation

The dataset's pixel labels (`Masks/`, fetch them into the sparse checkout) train an optional
12-channel segmentation head on the same features: `sonar-edge train ... --seg --seg-bg-w 0.1`;
mIoU is reported next to mAP (float and int8) and pooled by `sonar-edge cv`. The C runtime
emits the per-cell label map for such models (`se_segment`, `sonar-detect -s DIR`). See
`docs/M6-segmentation.md`.

## Report

`report/overview.tex` is a LaTeX overview of the data split (with worked
example pairs), the model and the C runtime; `report/overview.pdf` is the
compiled copy. Rebuild with `cd report && tectonic overview.tex`; the figure is
regenerated by `uv run python report/make_fig_pairs.py`.

## MCNN

The crop classifier MCNN and the reference crop classifiers (`src/sonar_edge/mcnn_cv.py`,
`src/sonar_edge/baselines/classifiers.py`) are continued in
[hogib/MCNN](https://github.com/hogib/MCNN) (module `sonar_cnn.scene`), which carries the
scene-fold and random-split results. The copies here are kept because the detector's
evaluation reuses their scoring code.
